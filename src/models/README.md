# วางโมเดล 3D (.glb) ที่นี่

เกมจะโหลดไฟล์ `.glb` จากโฟลเดอร์เหล่านี้ให้เองตอนเปิด (ไม่ต้องแก้โค้ด)
ถ้าโฟลเดอร์ไหนว่าง เกมจะใช้กล่องแบบง่ายแทน จึงเริ่มทีละอย่างได้

```
src/models/
├─ res/            ที่อยู่อาศัย
│   ├─ lv1/        บ้านเล็ก
│   ├─ lv2/        บ้านใหญ่ / ตึกเตี้ย
│   └─ lv3/        อาคารสูง / คอนโด
├─ com/            พาณิชย์ (lv1 ร้านเล็ก → lv3 ตึกสูง)
├─ ind/            อุตสาหกรรม (lv1 โกดัง → lv3 โรงงานใหญ่)
├─ power/          โรงไฟฟ้า
└─ park/           ต้นไม้ / ของตกแต่งสวน (วางสองชิ้นต่อช่อง)
```

- ใส่ได้หลายไฟล์ต่อโฟลเดอร์ เกมจะสุ่มใช้สลับกันให้เมืองไม่ซ้ำซาก
- ถ้ามีแค่ `lv1` เลเวลสูงกว่าจะใช้โมเดล lv1 แทน
- ใส่ไฟล์ไว้ในโฟลเดอร์ชนิดตรงๆ (เช่น `res/house.glb`) ได้ จะใช้กับทุกเลเวล
- ระบบย่อ/ขยายให้พอดีช่อง จัดกึ่งกลาง และวางบนพื้นให้อัตโนมัติ
- อาคารจะหันหน้าเข้าหาถนนที่อยู่ติดกัน ถ้าหันผิดด้าน แก้ `MODEL_YAW_OFFSET` ใน `src/main.js`
- ใช้ไฟล์ `.glb` แบบไม่บีบอัด (ไม่ใช่ Draco/Meshopt)

## โมเดล รถ / มอไซค์ / รถเมล์ / เรือ / หมา / แมว

วางไฟล์ `.glb` ในโฟลเดอร์เหล่านี้ (ใส่หลายไฟล์ได้ เกมจะสุ่มใช้):

    src/models/cars/    รถเก๋ง กระบะ แท็กซี่ ฯลฯ   (ใช้กับรถยนต์ทุกคันที่วิ่ง)
    src/models/bikes/   มอเตอร์ไซค์
    src/models/buses/   รถเมล์
    src/models/boats/   เรือ (ใช้แทนเรือทุกลำในแม่น้ำ)
    src/models/dogs/    หมา
    src/models/cats/    แมว

- เกมจะจัดโมเดลให้เอง: กึ่งกลาง วางบนพื้น หันแกนยาวไปทางหน้า-หลัง และย่อ/ขยายตามขนาดเกม
- ถ้าหัวรถหันผิดทาง แก้ค่า `VEH_YAW` ใน `src/vehicles.js` (เช่น `cars: Math.PI`)
- ปรับขนาดที่ `VEH_LEN` ในไฟล์เดียวกัน
- ถ้าโฟลเดอร์ไหนว่าง เกมใช้โมเดลที่สร้างจากโค้ดเหมือนเดิม
- ใช้ไฟล์เล็ก (low-poly, < 1 MB ต่อไฟล์) เพราะมีรถหลายสิบคันพร้อมกัน
- แหล่งโมเดลฟรี (ตรวจสอบสัญญาอนุญาตเอง): Kenney.nl (Car Kit, CC0), Quaternius (CC0), Poly Pizza
- รถที่ใช้โมเดล .glb จะไม่มีป้ายไฟแท็กซี่/ไฟหน้าไฟท้ายแยก และมอไซค์สายซิ่งจะไม่มีท่านอนขับ

### โฟลเดอร์เพิ่มเติม
    src/models/police/  รถตำรวจที่ด่านตรวจ (สุ่มใช้)
    src/models/cops/    ตำรวจที่ยืนที่ด่านตรวจ (สุ่ม สูงประมาณ 1 หน่วยคน)
    src/models/taxis/   แท็กซี่ (ใช้เฉพาะแท็กซี่ ไม่ใช่แกร็บ)

เครดิตโมเดลที่ใส่มาให้แล้วอยู่ท้าย README.md ของโปรเจกต์
    src/models/sports/  รถสปอร์ต (ใช้กับรถซิ่ง และสุ่มโผล่ในรถทั่วไป ~9%)

### สถานีตำรวจ / ดับเพลิง
    src/models/stations/police.glb   สถานีตำรวจ (2x2)
    src/models/stations/fire.glb     สถานีดับเพลิง (2x2)
หน้าอาคารต้องหัน +Z (ไฟล์ที่ให้มาปรับให้แล้ว) เกมย่อให้พอดีพื้นที่ 2x2 และยังมีลานจอดรถ/รถ/ต้นไม้ของเดิม ถ้าไม่มีไฟล์ใช้อาคารจากโค้ดเหมือนเดิม
