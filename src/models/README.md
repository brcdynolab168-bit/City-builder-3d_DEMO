# วางโมเดล 3D (.glb) ที่นี่

เกมจะโหลดไฟล์ `.glb` จากโฟลเดอร์เหล่านี้ให้เองตอนเปิด (ไม่ต้องแก้โค้ด)
ถ้าโฟลเดอร์ไหนว่าง เกมจะใช้กล่องแบบง่ายแทน จึงเริ่มทีละอย่างได้

```
src/models/
├─ res/            ที่อยู่อาศัย
│   ├─ lv1/        บ้านเล็ก
│   ├─ lv2/        บ้านใหญ่ / ตึกเตี้ย
│   └─ lv3/        อาคารสูง / คอนโด
├─ com/            พาณิชย์ (lv1 ร้านเล็ก → lv3 ตึกสูง)
├─ ind/            อุตสาหกรรม (lv1 โกดัง → lv3 โรงงานใหญ่)
├─ power/          โรงไฟฟ้า
└─ park/           ต้นไม้ / ของตกแต่งสวน (วางสองชิ้นต่อช่อง)
```

- ใส่ได้หลายไฟล์ต่อโฟลเดอร์ เกมจะสุ่มใช้สลับกันให้เมืองไม่ซ้ำซาก
- ถ้ามีแค่ `lv1` เลเวลสูงกว่าจะใช้โมเดล lv1 แทน
- ใส่ไฟล์ไว้ในโฟลเดอร์ชนิดตรงๆ (เช่น `res/house.glb`) ได้ จะใช้กับทุกเลเวล
- ระบบย่อ/ขยายให้พอดีช่อง จัดกึ่งกลาง และวางบนพื้นให้อัตโนมัติ
- อาคารจะหันหน้าเข้าหาถนนที่อยู่ติดกัน ถ้าหันผิดด้าน แก้ `MODEL_YAW_OFFSET` ใน `src/main.js`
- ใช้ไฟล์ `.glb` แบบไม่บีบอัด (ไม่ใช่ Draco/Meshopt)
