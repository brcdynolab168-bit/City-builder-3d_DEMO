# Mini City 3D

เกมสร้างเมือง 3D บนเว็บ (Three.js + Vite)

## รันในเครื่อง

```
npm install
npm run dev
```

เปิด http://localhost:8080

## เอาขึ้นเว็บให้เข้าได้จากทุกที่ (GitHub Pages)

1. push โค้ดขึ้น GitHub (สาขา `main`)
2. Settings → Pages → Source เลือก **GitHub Actions**
3. รอแท็บ Actions เป็นสีเขียว แล้วเปิด `https://<username>.github.io/<ชื่อ repo>/`

ทุกครั้งที่ push โค้ดใหม่ขึ้น `main` เว็บจะอัปเดตเอง

## ควบคุม

- ทัชแพด: ลากสองนิ้ว = เลื่อน, หนีบนิ้ว = ซูม, Alt/Option + สองนิ้ว = หมุน
- เมาส์: ซ้ายสร้าง, ขวาหมุน, ล้อซูม
- หน้าจอสัมผัส: แตะนิ้วเดียว = สร้าง, สองนิ้ว = เลื่อน/ซูม
- แผงขวาบน: ปรับกราฟิก ต่ำ/กลาง/สูง และโหมดควบคุม
