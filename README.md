# Mini City 3D

เกมสร้างเมือง 3D บนเว็บ (Three.js + Vite)

## รันในเครื่อง

```
npm install
npm run dev
```

เปิด http://localhost:8080

## เอาขึ้นเว็บให้เข้าได้จากทุกที่ (GitHub Pages)

1. push โค้ดขึ้น GitHub (สาขา `main`) ด้วย GitHub Desktop: Commit → Push origin
2. Settings → Pages → Source เลือก **GitHub Actions**
3. รอแท็บ Actions เป็นสีเขียว แล้วเปิด `https://<username>.github.io/<ชื่อ repo>/`

ทุกครั้งที่ push โค้ดใหม่ขึ้น `main` เว็บจะอัปเดตเอง (กด Ctrl+F5 เพื่อโหลดใหม่)

## วิธีเล่น

1. สร้าง **ถนน** ก่อน แล้ววางโซน ที่อยู่อาศัย / พาณิชย์ / อุตสาหกรรม **ติดถนน**
2. ต้องมีทั้ง **โรงไฟฟ้า** และ **โรงประปา** ตึกถึงจะโตขึ้น (ดูตัวเลข ไฟฟ้า/น้ำ ที่แถบบน สีแดง = ไม่พอ)
3. **โรงประปา** ต้องตั้งใกล้แม่น้ำหรือทะเล (ภายใน 3 ช่อง) ฝนตกน้ำดิบเพิ่ม อากาศร้อนคนใช้น้ำมากขึ้น
4. แม่น้ำสร้างอะไรทับไม่ได้ ยกเว้น **สะพาน** (เลือกถนนแล้วลากข้าม ช่องละ $40)
5. **สวน** ทำให้ที่อยู่อาศัยรอบๆโตเร็วขึ้น และมีคนมาเดินเล่น

## โลกในเกม

- **ภูมิประเทศ**: เนินเขา แม่น้ำไหลลงทะเล ภูเขาและป่าล้อมรอบ (ทิศตะวันออกเป็นหาด)
- **ประชากรจริง**: จำนวนรถ คน หมา แมว คำนวณจากประชากรและงานในเมือง
  เช้า-เย็นรถเยอะ กลางคืนเงียบ ฝนตกคนเดินน้อยลง รถช้าลง ระดับกราฟิกคือเพดานจำนวนสูงสุด
- **ถนน**: ทางแยกมีไฟจราจร (รถและคนหยุดตามไฟแดง) ทางม้าลาย เส้นหยุด
  ป้ายชื่อถนน ป้ายคนข้ามถนน ป้ายจำกัดความเร็ว ป้ายที่จอดรถ (กราฟิกกลางขึ้นไป)
- **สภาพอากาศ**: เมฆลอยตามลม ฝน พายุฟ้าแลบ ถนนเปียก ต้นไม้โยกตามลม
  เปลี่ยนเองทุก 1-3 นาที หรือเลือกเองที่แผงขวา
- **เวลา**: กลางวัน/กลางคืน นาฬิกาและอุณหภูมิบนแถบบน

## ควบคุม

- ทัชแพด: ลากสองนิ้ว = เลื่อน, หนีบนิ้ว = ซูม, Alt/Option + สองนิ้ว = หมุน
- เมาส์: ซ้ายสร้าง, ขวาหมุน, ล้อซูม
- หน้าจอสัมผัส: แตะนิ้วเดียว = สร้าง, สองนิ้ว = เลื่อน/ซูม
- แป้น 1-9 เลือกเครื่องมือ, Esc ยกเลิก, Space หยุด, Q/E หมุน, +/- ซูม
- แผงขวาบน: ปรับกราฟิก ต่ำ/กลาง/สูง, สภาพอากาศ, โหมดควบคุม

## เมนู แผนที่ เซฟ ภาษา เสียง (อัปเดตล่าสุด)
- **หน้า Intro**: เล่นต่อ / เกมใหม่ (เลือกแผนที่ 4 แบบ: แม่น้ำ, ชายฝั่ง, ทะเลสาบ, เกาะ) / โหลดเกม / ตั้งค่า
- **เซฟหลายช่อง**: เก็บใน localStorage ของแต่ละเครื่อง เปลี่ยนชื่อ คัดลอก ลบได้จากเมนูโหลดเกม (กด Esc หรือปุ่ม "เมนูหลัก" ระหว่างเล่น)
- **3 ภาษา**: ไทย / English / 中文 (ปุ่มมุมขวาบนของเมนู หรือในตั้งค่า)
- **เวลา**: 1 วันในเกม = 5 นาทีจริง (1x) ท้องฟ้า เงิน และตัวนับวันเดินพร้อมกัน
- **เสียง**: สร้างด้วย WebAudio ไม่ต้องมีไฟล์เสียง ซูมเข้าใกล้จะได้ยินรายละเอียดชัดขึ้น (นก รถ ผู้คน น้ำ ฯลฯ)
- **ม.กรุงเทพ**: อยู่ในปุ่ม "บริการ" (โมเดลสไตล์จำลอง ไม่ใช่แบบจำลองจริง)

## อัปเดต: อาคารหลายช่อง, ศาสนสถาน, ฟาร์ม, อุบัติเหตุ, แสงเงา RTX

- **อาคารหลายช่อง**: ม.กรุงเทพ (3×3 ตึกเหลี่ยมขาว-กระจก สระสะท้อนแสง), โรงพยาบาล 2×2, โรงเรียน 3×2, ห้างสรรพสินค้า 3×2, ตลาด 2×2, ร้านขายรถ 2×1, ร้านอุปกรณ์ตกปลา, วัด 3×3, โบสถ์คริสต์ 2×3, มัสยิด 3×3
- **ฟาร์ม** (เครื่องมือใหม่ ปุ่ม 0): นาข้าว, ไร่ผัก+โรงเรือน, สวนผลไม้, ฟาร์มปศุสัตว์ — ไม่ต้องติดถนน
- **สวน** มีหลายแบบ: สวนเล็ก, สนามเด็กเล่น, ลานน้ำพุ, สนามกีฬา, สวนพฤกษศาสตร์
- ปุ่ม **R** หมุนอาคาร (ค่าเริ่มต้น: หันหน้าเข้าหาถนนเอง), เส้นเหลืองที่ขอบกรอบเขียว = ด้านหน้าอาคาร, รื้อ (B) คลิกตรงไหนก็รื้อทั้งหลัง
- **อุบัติเหตุ**: รถชนเป็นครั้งคราว (ฝนตกบ่อยขึ้น) มีควัน ไฟฉุกเฉิน กรวยจราจร รถคันหลังติดคิว รถพยาบาลมาช่วยพร้อมไซเรน แล้วเคลียร์ถนน
- **ช่วงเวลา**: เช้า สาย เที่ยง บ่าย เย็น มืด กลางคืน เที่ยงคืน ก่อนรุ่ง แสดงข้างนาฬิกา, ท้องฟ้าเปลี่ยนสี มีดวงอาทิตย์ ดวงจันทร์ ดาว
- **กราฟิก RTX**: เพิ่มปุ่ม RTX (AO, เงา 4096, ไฟเรือง) — เป็นการจำลองแบบแรสเตอร์ ไม่ใช่เรย์เทรซิงจริง
- เสียง: หมาหอนตอนดึก (บ่อยสุดช่วงเที่ยงคืน), เสียงรถชน, ไซเรนรถพยาบาล
- โมเดลรถ (ซีดาน/แฮทช์แบ็ก/เอสยูวี/กระบะ), คน (28 แบบ), หมา, แมว ปรับให้ละเอียดขึ้น
- ทางลัดคีย์ใหม่: 0 = ฟาร์ม, B = รื้อ, R = หมุนอาคาร

## ประสิทธิภาพ
- รวมชิ้นส่วนนิ่งของแต่ละช่องเป็นก้อนเดียวต่อวัสดุ (ลด draw call มาก)
- อัปเดตแผนที่เงาเป็นช่วงๆ (~15 ครั้ง/วินาที) แทนทุกเฟรม
- ปรับความละเอียดภาพอัตโนมัติเมื่อ FPS ตก (ต่ำกว่า 38) และเพิ่มกลับเมื่อลื่น (เกิน 58)

## อัปเดต: ข่าวเมือง / เหตุการณ์ / ข้อมูลประชากร
- **สถานีตำรวจ** (2×2), **สถานีดับเพลิง** (2×2) ในเมนูบริการ และ **ร้านทอง** ในเมนูพาณิชย์
- **ข่าวเมือง** (มุมซ้ายล่าง): อุบัติเหตุ (ชนท้าย แข่งรถ ปาดหน้า ถนนลื่น) มีผู้บาดเจ็บ/เสียชีวิต, คลิปลงเพจ, ไฟ/น้ำขาด, งาน, รถติด, ไฟไหม้, โจรปล้นร้านทอง, ข่าวทั่วไปตามสิ่งที่มีในเมือง
- มีตำรวจ → อุบัติเหตุ/ปล้นลดลง จับโจรได้; มีดับเพลิง → ดับไฟไว ไม่มี → ตึกวอด
- **ข้อมูลประชากร**: คลิกช่องประชากร หรือปุ่มในแผงขวา — ชาย/หญิง วัย 4 กลุ่ม งาน รถ หมา แมว ความพอใจ และความต้องการของประชาชน
- ตึก/บ้านที่เติบโตเองสุ่มรูปแบบมากขึ้น ไม่ซ้ำกัน

## อัปเดต: สวนเล็กหลายแบบ (1×1)
สวนดอกไม้ สวนป่าเล็ก น้ำพุเล็ก สระบัว ศาลาในสวน สวนหินญี่ปุ่น ลานปิกนิก สนามบาสเก็ตบอล ลานออกกำลังกาย สวนสุนัข — เลือกจากเครื่องมือ "สวน" (กด 8 ซ้ำหรือเมนูตัวเลือกด้านบน)

## ปรับสมดุลโรงไฟฟ้า/ประปา
กำลังผลิตเพิ่มประมาณ 3–4 เท่า (ก๊าซ 450, โรงใหญ่ 1200; ประปากลาง 500, ใหญ่ 1300) ค่าดูแลลดลง ไม่ต้องสร้างโรงเยอะอีกต่อไป

## หน้าต่างข้อมูลเมือง (กด I หรือคลิกช่องเงิน/ประชากร/ไฟ/น้ำ)
แท็บ: ภาพรวม · ประชากร · ไฟ-น้ำ (โรงผลิต/ใครใช้มากสุด) · การเงิน (รายได้-รายจ่ายแยกหมวด) · อาคาร (นับตามประเภท) · ข่าว

## ทางลาดขึ้นสะพาน
ถนนฝั่งดินใกล้แม่น้ำค่อยๆ ลาดสูงขึ้นตลอด 6 ช่อง และผิวถนนเอียงตามความชัน ไม่เป็นขั้นบันไดโดดสูงทันที (ปรับความยาวทางลาดที่ `RAMP_LEN`, ความสูงสะพานที่ `BRIDGE_Y` ใน main.js)

## ปรับประสิทธิภาพรอบใหม่ + เสียงสถานที่
- รถ: รวมกระจก/ชิ้นส่วน/ไฟเป็นก้อนเดียว (5 → 3 draw call ต่อคัน); คน/หมา/แมว: ไกลจากกล้อง = โมเดลรวมชิ้นเดียว (1 draw call) ใกล้ = แกว่งแขนขา, ไกลมาก = ซ่อน, ไม่ทอดเงา
- เสียงประจำสถานที่เมื่อซูมเข้าใกล้: สถานีตำรวจ (วิทยุ/ไซเรน), ดับเพลิง (กริ่ง/เครื่องยนต์/แตร), วัด (ระฆัง/ฆ้อง), โบสถ์ (ระฆัง), ตลาด/ห้าง (เสียงพ่อค้าแม่ค้า)

## อัปเดตใหญ่: รัฐ/เอกชน, ธนาคาร, ขนส่ง, รถซิ่ง, ภาษี, ทะเบียนราษฎร์
- **โรงพยาบาลรัฐ/เอกชน, โรงเรียนรัฐ/เอกชน** (เอกชนสร้างภาษีเพิ่ม แต่ครอบคลุมน้อยกว่า), **ธนาคาร** (โดนปล้นได้)
- **อู่รถเมล์ / อู่แท็กซี่ / จุดรวมแกร็บ** มีรถเมล์ แท็กซี่ แกร็บ (รถและมอไซค์) วิ่งจริง; รถเมล์ลดรถติด
- มอเตอร์ไซค์วิ่งปนกับรถทั่วไป; **กลุ่มรถซิ่งมอไซค์/รถยนต์** ป่วนถนน (กลางคืนบ่อยกว่า) ฝ่าไฟแดง มีเสียงเร่งเครื่อง เสี่ยงชนและเสียชีวิต ตำรวจช่วยลดและจับกุม
- **ภาษีแยกชนิด** ในแท็บการเงิน: ที่ดิน, เงินได้, VAT, นิติบุคคล, อุตสาหกรรม/เกษตร, ยานพาหนะ, ธุรกิจเฉพาะ (ธนาคาร/ทอง), รพ./โรงเรียนเอกชน, ขนส่ง
- **ทะเบียนราษฎร์** (แท็บใหม่): บันทึกการเกิด/เสียชีวิต พร้อมชื่อ อายุ สาเหตุ (ชรา โรค อุบัติเหตุ แข่งรถ ไฟไหม้) สถานที่ และสถิติ
- แก้หางหมาที่ดูหลุดออกจากตัว


## อัปเดต: UI สไตล์ Steam + ระบบก่อสร้าง + เรือ + รถยก + สถานบันเทิง
- **UI ใหม่ทั้งหมด**: แถบสถานะด้านบน (เงิน/ประชากร/ไฟ-น้ำพร้อมมิเตอร์/ความต้องการ RCI/เวลา-อากาศ/ความเร็ว), รางปุ่มขวา (ข้อมูลเมือง / ตั้งค่า / ข่าว / ซ่อน UI), แผนที่ย่อมุมขวาล่าง (คลิก/ลากเพื่อย้ายกล้อง), แถบเครื่องมือแบบ dock ด้านล่าง
- **ข้อมูลเมืองเป็นลิ้นชักซ้ายแยกต่างหาก**: ปิดได้ด้วยปุ่ม ✕ / กด Esc / กด I / **ลากหัวหน้าต่างไปทางซ้ายแล้วปล่อย**
- **ตึกโตช้าลง + แอนิเมชันก่อสร้าง**: รั้วไซต์งาน → ขุดฐาน → ตึกสูงขึ้นทีละชั้นพร้อมนั่งร้านคลุมตาข่าย เครนหอคอยหมุน ฝุ่น → รื้อนั่งร้านแล้วมีฝุ่นฟุ้งตอนเสร็จ (อาคารที่กำลังสร้างยังไม่นับคน/งาน/ไฟ/น้ำ)
- **เรือ 6 แบบ**: ประมง, หางยาว, เรือใบ, เรือพายชาวบ้าน, เรือลากจูงบรรทุกตู้, เรือโดยสาร (แก้บัคเริ่มบนบก/กลับลำตรงสะพาน/รอยน้ำ)
- **รถยก**: อุบัติเหตุ/รถเสียข้างทาง → รถพยาบาล (ถ้ามีผู้บาดเจ็บ) → รถยกมาใช้สลิงลากรถขึ้นกระบะแล้วพาไปอู่
- **สถานบันเทิง, ร้านแต่งรถ, สนามแข่งรถคลอง 5 (3×7)**, ภาษีกลุ่ม "สถานบันเทิง/มอเตอร์สปอร์ต"
- **เมาแล้วขับ** (กลางคืน เมื่อมีสถานบันเทิง) และ **ด่านตรวจสุ่ม** ของตำรวจ (ไม่บ่อย ~70 วินาที ลดเหตุเมาแล้วขับ ปรับเงินเข้าเมือง)
- **สนามแข่งคลอง 5 ใช้งานจริง**: สุ่มวันจัดงาน (~40% ของวัน) เริ่มช่วง 17:30–23:00 รถทยอยเข้าต่อแถว จับคู่ขึ้นเส้นสตาร์ท ไฟต้นคริสต์มาส ออกตัวแข่งจริงจนข้ามเส้นชัย ผู้ชมแน่นอัฒจันทร์ จุดพลุ มีเสียงรถ/พลุ/เสียงเชียร์
- **เสียงอาซาน** (YouTube 6R44AxFn1p4): โหมดดูเมือง กดมัสยิด 3 ครั้งติด = เปิด, กดมัสยิด 1 ครั้ง = ปิด (ฝังเครื่องเล่นซ่อน ต้องต่อเน็ต)
- **ดับเบิลคลิกรายการข่าวที่มี 📍** (ในแผงข่าวหรือแท็บข่าวของข้อมูลเมือง) → กล้องบินไปจุดเกิดเหตุพร้อมวงแหวนกะพริบ (อุบัติเหตุ ไฟไหม้ ปล้น รถซิ่ง ด่านตรวจ งานแข่ง)
